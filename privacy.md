# Privacy Policy — Job Agent Mailer

Last updated: October 8, 2026

Job Agent Mailer is a personal tool used only by its owner.

## Information used

The tool uses the Gmail API with send-only permission to send job-tracker emails from the owner's dedicated Gmail account. It does not read, search, download, modify, or delete Gmail messages.

The tool may process job-listing information, a private resume summary, and a private Excel application tracker. This information remains in the owner's private GitHub repository and personal devices.

## Sharing

Job Agent Mailer does not sell, share, or provide personal information to third parties. Email is sent only to the recipient email address selected by the owner.

## Security

OAuth credentials and email tokens are stored as private GitHub Actions Secrets and are not committed to the public information repository.
